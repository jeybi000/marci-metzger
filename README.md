# Marci Metzger Real Estate

Responsive homepage prototype for Marci Metzger, REALTOR® at The Ridge Realty Group in Pahrump, Nevada.

## Features

- **Hero Section**: Responsive landscape hero with optimized text contrast overlay and quick call-to-actions.
- **Property Search Form**: Filterable sample listings by location, property type, price, beds, and baths.
- **Featured Gallery Carousel**: Interactive photo carousel with thumbnail navigation, fullscreen lightbox view, and touch swipe support.
- **Services Showcase**: Commercial, residential, and real estate guidance services.
- **About & Credentials**: Professional background, achievements, and affiliations.
- **Contact Form & Direct Details**: Clear contact options and office location information.

## Getting Started

Serve the static files locally using any HTTP server:

```bash
# Using Node.js serve
npx serve .

# Or using Python
python -m http.server 3000
```

Open `http://localhost:3000` in your web browser.
